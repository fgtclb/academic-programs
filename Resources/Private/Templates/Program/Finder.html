The form submits to the list plugin on the target page, in the argument shape of the list's own filter form: `tx_academicprograms_programlist[demand][filterCollection][]` with one category uid each. The list answers the POST with a redirect to its filtered URL. `listUri` is empty without a target page that can be linked, and `filterTypes.visible` without a category type that has categories: either way there is nothing to offer, so no form renders.
