The application link of the program page: the page or URL of the field "Application link", labelled with the field "Label of the application link", or "Apply now" when the editor left the label empty. An empty link renders nothing. A sibling of the header rather than part of it, so a project that replaces "Program/Page/Header" keeps the link. It needs "program" alone, so a list item renders it as well, which is why its class is a block of its own rather than an element of "academic-programs-detail". Resolved first, so a target that cannot be linked - a hidden or deleted page, or an untranslated one in a language without a fallback - renders no link rather than the bare label.
