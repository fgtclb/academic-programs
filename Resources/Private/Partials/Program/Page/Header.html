The header of the program page: a link back to the program list, the title and the subtitle. The link is rendered when the site setting "plugin.tx_academicprograms.page.listPid" names a page that can be linked; "programListPid" is that page, or "0". One element, because the page template renders it inside a reversed flex column together with the media: the image is shown above the header, the heading stays first in the document.
Resolved first, so a list page that cannot be linked - hidden, or not translated - renders no link rather than the bare label. {f:translate(key: 'page.backToList', extensionName: 'academic_programs')}
