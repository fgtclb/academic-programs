The facts of a program, in the order given: the program page, the details content element and the program card render them through this partial. "facts" is the list of ProgramFact objects built from the field list of the place, "listClass" and "itemClass" are classes added to the list and to each of its items. One fact is one "Program/Facts/Item", so a project that changes one row overrides that partial rather than this one.
