`filterTypes.visible` holds the category types to offer, in the order to offer them, and only types with categories: the filter types of the element or the site, or every type of the group with categories when neither sets any. Without `filterTypes` - a project controller that overrides `listAction()`, or a template that renders this partial with arguments of its own - every type with categories is offered in the type order of the group, as before the filter types existed.
