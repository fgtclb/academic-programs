A change of a select submits nothing by itself: the module `program-list.js` updates the list in place, or submits the form where the list template lacks the parts it needs, see `Program/List.html`. `data-academic-programs-list-form` marks the form for the second case. The module hides the column of the submit button, `data-academic-programs-list-submit`, which is what a visitor without JavaScript submits the form with. A select that keeps an inline `onchange` handler, from an override of a filter partial, is left to that handler.
The active filters, the reset link and the result count are switched on per site by `settings.filter.showActiveFilters`, `showReset` and `showResultCount`. The first two belong to the filter, so a list whose filter is hidden shows neither.
