The page template of the program page type. It renders the section "Main" of the page layout of the site, "Default" unless the site setting "plugin.tx_academicprograms.page.layout" names another one. A site without a layout "Default" gets the fallback layout of this extension, which renders the section alone; a layout the setting names has to exist. Each part is a partial below "Program/Page/", so a project replaces one of them rather than this file. The page record: the record of the page information object "page" a PAGEVIEW page object assigns, or "data" of a FLUIDTEMPLATE page object. "page" first, because PAGEVIEW reserves that name, while a PAGEVIEW site package may assign a "data" of its own.
The link is rendered when the site setting "plugin.tx_academicprograms.page.listPid" names a page that can be linked; "programListPid" is that page, or "0". Resolved first, so a list page that cannot be linked - hidden, or not translated - renders no link rather than the bare label. {f:translate(key: 'page.backToList', extensionName: 'AcademicPrograms')}
