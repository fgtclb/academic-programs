The page template of the program page type. It renders the section "Main" of the page layout of the site, "Default" unless the site setting "plugin.tx_academicprograms.page.layout" names another one. A site without a layout "Default" gets the fallback layout of this extension, which renders the section alone; a layout the setting names has to exist. Each part is a partial below "Program/Page/", so a project replaces one of them rather than this file.
